* Life cycle method in React :: 

It has Three stages. 1.Mounting 2. Updating 3. Unmounting
1. Mounting Phase : has three things. (1). Constructor(): called when component is created. initializing 
component state and bind event handlers
* (2).static getDerivedStateFromProps() : This method is invoked before rendering both on initial mount and
on subsequent updates. It allows you to update the state based on the changes in props   
(3): render(): This method is responsible for rendering the components jsx markup. 
(4).ComponentDidMount() : This method is immediately called when component has been mounted to the DOM. It is 
commonly used to initiate APi calls or set up event listener.
2. Updating Pase: *) static getDerivedStateFromProps() *)shouldComponentUpdate() : determines should re-render/not
*)render() called again to update the components UI *)getSnapShotBeforeUpdate() : This method is called right
before the changes are committed to the DOM. Capture info before potential change. *)ComponentDidUpdate() This 
method is invoked after the component has been re-rendered and the changes have been applied to the DOM . used 
for updating DOM based on props and states changes.
3. Unmounting Phase:  *)componentWillUnmount() This method is called right before the component is removed 
from th DOM. It can be used for cleanup tasks.or cancelling api requests.
